# Travessia do Nilo

Companheiro digital para o tabuleiro físico: abertura animada, dado opcional de argila, 48 perguntas, 8 cartas do Faraó e 8 Pragas, com as artes originais recortadas dos anexos.

Abra `index.html` ou publique a raiz no GitHub Pages. Não exige instalação nem servidor de aplicação.

## Regras
As perguntas usam o mesmo baralho no Nilo e no deserto. Acertar permite avançar **2 casas**: esta regra prevalece sobre o texto de 1 casa nas artes originais, que foram preservadas. Os peões e penalidades são acompanhados no tabuleiro físico. Cada clique sorteia uma carta de forma independente, com reposição e sem limite de retiradas. Toque diretamente no verso de um baralho para revelar uma carta com animação de perspectiva.

## Orientações
O espaço do vídeo está em `index.html`, dentro de `modal-ajuda`. Substitua a caixa `reservado` por seu vídeo quando estiver pronto.

## Acessibilidade
Teclado, fechamento com Escape, foco limitado aos diálogos e respeito à preferência de movimento reduzido.
